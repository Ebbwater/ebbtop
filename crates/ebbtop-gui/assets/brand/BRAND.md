# EbbTop brand

EbbTop (`ebbtop`) is the native, btop-style monitor window for Ebbwater hosts. This pack is its identity: the mark, the wordmark and lockups, the app icon, the favicons and the window icon, all inside the Ebbwater system.

## The mark: Ledger

Three forward-leaning slabs, stacked and sorted with the longest on top, like `top`'s process list.

- **Left ends ride one forward slash.** The slabs are never joined, but their left ends line up on the Ebbwater lean (33.6 : 52), so the driftmark's slash appears through the alignment rather than being drawn.
- **Right ends settle on the grid edge.** Because the left ends drift right as you go down, each row comes out shorter than the one above: the sort is built into the geometry, not added on top.
- **Gaps are waterlines.** Each gap is 8 units, the height of the Ebbwater waterline cut. They must always stay open.
- **The top row is lit.** Only the top row is teal. It is the "top" in EbbTop and matches TOP in the wordmark.

It also reads as a leaning **E**, for Ebb.

EbbTop inherits the Ebbwater *system* (grid, lean, cut, tokens, flat colour, zero radius) but not the parent driftmark. Never use the Ebbwater driftmark, the Labs beaker or WantNot's bar mark to stand for EbbTop.

### Construction

| | |
|---|---|
| Grid | 96 × 96 units |
| Lean | 33.6 : 52 (dx : dy), forward only |
| Rows | 3, each 26.667 units tall |
| Gap | 8 units |
| Row *i* | `(lean·yt, yt) (96 − lean·h, yt) (96, yb) (lean·yb, yb)` |
| Clearspace | one row height (0.278 × mark height) on every side |
| Corners | square |

Everything is generated by `tools/build_ebbtop.py`; change the geometry there, never by hand.

## Colour

| Token | Hex | Use |
|---|---|---|
| Graphite | `#23272B` | ink on light, tile and dark ground |
| Teal | `#2AA79B` | the lit row and TOP, light grounds only |
| Teal Bright | `#3BC4B6` | the lit row and TOP, dark grounds only |
| Frost | `#F5F7F8` | light ground, ink on dark |
| Slate | `#6B7680` | secondary UI, hairlines |
| Mist | `#9AA6AD` | dividers, construction lines |

- **Light:** graphite rows, teal top row, on Frost or white.
- **Dark:** frost rows, Teal Bright top row, on Graphite.
- Teal appears **once** per screen: the mark's top row and TOP count as one use when they appear together in the lockup.
- **One-colour** (`ebbtop-mark-graphite.svg`, `ebbtop-mark-frost.svg`) only where the medium can't carry two inks: terminal glyph art, embossing, single-ink print.

## Wordmark and lockup

- **EBBTOP** in Exo 2 Medium, all caps, −0.04em tracking, with the font's own kerning.
- Only the name splits colour: **EBB** in ink, **TOP** in teal. Headlines stay single-colour.
- Lockup: mark, then a one-row gap, then the wordmark. Cap height equals mark height, baselines align with the bottom row, and everything sits flush left.
- Display name **EBBTOP**; in prose **EbbTop**; command and binary **`ebbtop`** (lowercase, always).
- The wordmark is outlined paths. Never set it as live `<text>`.

## App icon

- Graphite tile, zero radius, mark at 61 % of the tile, centred.
- Frost rows, Teal Bright top row.
- **Below 64 px use the hinted files** (`ebbtop-app-icon-16/24/32/48/64.svg`, and the PNG and ICO ladders). Their rows and gaps snap to whole pixels, so every gap stays at least one clear pixel row. Never scale the 512 master down to small sizes.

| Size | Row px | Gap px | Mark px |
|---|---|---|---|
| 16 | 3 | 1 | 11 |
| 24 | 4 | 1 | 14 |
| 32 | 5 | 2 | 19 |
| 48 | 8 | 3 | 30 |
| 64 | 11 | 3 | 39 |

(Full ladder in `tools/hinting.json`.)

## Minimum sizes

- Mark from the master SVG: 24 px.
- Mark at 16–20 px: only through the hinted icon files.
- Lockup: 24 px mark height.
- Favicon: 16 px.

## Don't

- Add gradients, outlines, shadows or rounded corners.
- Close, narrow or fill a gap.
- Light any row but the top, light more than one row, or make the whole mark teal.
- Reorder the rows, mirror the lean, or rotate the mark.
- Add ticks, graphs, gauges or liquid to the mark. Measurement belongs in the UI.
- Put the mark on Teal, on photos, or on mid-tone greys.
- Stretch it, or set the lockup with any font other than Exo 2 Medium.

## Wiring into ebbtop (done)

1. `rgba/ebbtop-64.rgba` → `crates/ebbtop-gui/assets/ebbtop.rgba`. It is the same 64×64 RGBA8 layout `main.rs` loads as the window icon; straight (not premultiplied) alpha.
2. `ico/ebbtop.ico` replaced the 64-only icon `build.rs` generated, giving Windows proper hinted 16–48 px frames.
3. README heading: `ebbtop-lockup.svg` (or `-dark` for dark-mode readers).
